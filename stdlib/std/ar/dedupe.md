[[explore]] Several researchers each build one core approach to the same task. Same core means the same main mechanism that decides what the solution does (the same kind of model, algorithm or signal); differing only in parameters, filters, exits, sizing or added gates still counts as the same, while a different main mechanism is a different core even when it shares ingredients.
[[exploit]] Several researchers each build one refinement of the same solution. Same means the same change to the same part of the solution (the same rule, component or parameter, changed the same way); a change to a different part, or a different kind of change, is a different refinement.
